Networking Multiplayer

During this course, I explored the fundamental concepts of C++ multiplayer system development. Through several practical assignments, I applied these concepts using Unreal Engine 5.

Topics covered

Core networking skills and concepts

Here are the main topics explored during this multiplayer programming course:

  • Network Architectures: Dedicated Server vs. Peer-to-Peer (P2P) models, protocols (TCP/UDP), and basic connection concepts (IP, Ports, LAN).
  • Replication and Authority: Principle of Server Authority, variable/actor replication, and Remote Procedure Calls (RPCs - Server, Client, Multicast).
  • Gameplay Framework (Unreal): Use of network classes (GameMode, GameState, PlayerState, PlayerController) and game state synchronization.
  • Transitions (Traveling): Managing multiplayer map changes (ClientTravel, ServerTravel) with and without interruption (Seamless Travel).
  • Lag Compensation: Techniques to counter latency (Ping, Server Reconciliation, Rewinding Time for hit validation).
  • Network Optimization: Bandwidth reduction (Network Profiler), relevancy management (Relevancy, Net Cull Distance), and Net Dormancy.
  • Online Services (Online Subsystem): Integration of third-party services (Steam, Epic) for session creation (Lobbies, Matchmaking) and Achievements.

Practical implementation

Practical assignments with Unreal Engine 5

The theory from this course was put into practice through three projects developed in C++ using Unreal Engine, addressing the real challenges of multiplayer development:

  • Lobby System and Synchronization: Creation of a waiting area to host or join a game. Implemented character selection, latency-tolerant countdown synchronization, and seamless transition (Seamless Travel) to the game map.
  • Latency Compensation (Server Rewind): Development of an advanced mechanic to validate player shots on the server side. The system "rewinds time" to verify the accuracy of a shot based on the client's perspective at the moment of the action, supporting pings of up to 500 ms.
  • Steam Online Subsystem Integration: Replacing direct IP connections with Steam's infrastructure. Implemented matchmaking (hosting and searching for sessions via filters) and unlocking Achievements directly linked to the Steam account.
